# FireWeave agent instructions

FireWeave's contract for coding agents in this repository. The order every change follows is
in the repository-root `AGENTS.md` (**FireWeave — rollout contract**); this file indexes the
detail, one topic per file under `.fireweave/instructions/`, so read only the topic your task
needs. Generated by FireWeave setup; `/fireweave:initialise --reinit` regenerates it. Edit the
code these files point at, not the files.

## Rollout-ready layout

Read `.fireweave/instructions/layout.md`: one row per app, with its control-points, start, build-config, stamps and metrics files.

## Does this task qualify?

Read `.fireweave/instructions/qualify.md`: classify the task in one line before step 1, and what never to do.

## Every feature change — HARD ORDER

Read `.fireweave/instructions/hard-order.md`: each step of the order in full, with the stamp policy and the absence names.

## Before you add a metric

Read `.fireweave/instructions/before-a-metric.md`: the one capabilities read per change that decides whether it adds metrics.

## Deriving `telemetry.metrics`

Read `.fireweave/instructions/deriving-metrics.md`: which signals a change owes, by `changeType`.

## Cohort identity

Read `.fireweave/instructions/cohort-identity.md`: the always-on identity bind, per surface.

## Manifest contract

Read `.fireweave/instructions/manifest-contract.md`: the manifest's exact shape: copy it, never invent it.
