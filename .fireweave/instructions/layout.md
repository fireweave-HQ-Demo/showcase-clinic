No harness module: never add `fw-harness`, `fw-providers` or a second FireWeave setup file.

Rollout-ready manifests and change stamps are **server-owned**: reach them through
`fw tool upsert-rollout-manifest` and the resolution seam. There is no
directory under `.fireweave/` to read or write for them.

Gitignored runtime paths: `.fireweave/.cache/` (the server projection), `.fireweave/.queue/`
(author state not yet synced — never delete it to clear a warning) and `.fireweave/.lock`.
